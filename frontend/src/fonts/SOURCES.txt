Self-hosted fonts for randscan. No network fonts: the woff2 files ship with the app and are
loaded through next/font/local (src/app/[lang]/layout.tsx).

Geist-Variable.woff2, GeistMono-Variable.woff2
  Geist and Geist Mono (Vercel with basement.studio), from the `geist` npm package v1.9.2 —
  https://registry.npmjs.org/geist/-/geist-1.9.2.tgz
  taken verbatim from `dist/fonts/geist-sans/Geist-Variable.woff2` and
  `dist/fonts/geist-mono/GeistMono-Variable.woff2` inside that tarball.
  Geist sets the text and headings; Geist Mono sets eyebrows, table headers, hashes, keys and
  figures. Licence: Geist-OFL.txt (SIL Open Font License 1.1), the tarball's LICENSE.txt.

DepartureMono-Regular.woff2
  Departure Mono v1.500 (Helena Zhang) —
  https://github.com/rektdeckard/departure-mono/releases/download/v1.500/DepartureMono-1.500.zip
  taken verbatim from `DepartureMono-Regular.woff2` inside that archive. A pixel face on an 11 px
  grid: used only for the randscan wordmark, so the logo is the same as the wallet's.
  Licence: DepartureMono-OFL.txt (SIL Open Font License 1.1), the archive's LICENSE.

The faces are reached through --font-sans / --font-mono / --font-display.
